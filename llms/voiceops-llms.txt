# VoiceOps

> VoiceOps (voiceops.com) is an AI agent platform that analyzes customer conversations — calls, email, SMS, and chat — and turns them into structured business intelligence: transcription and analysis across 120+ languages, CRM enrichment, lead scoring, compliance monitoring, competitive intelligence, and churn detection for high-velocity sales, CX, and operations teams. Backed by Bain Capital Ventures. VoiceOps pipes structured conversation records into tools like Salesforce, HubSpot, Genesys, Five9, Snowflake, Power BI, Slack, Microsoft Teams, and outbound webhooks.

VoiceOps operates a live, first-party remote **MCP server** at `https://mcp.voiceops.com/mcp` — JSON-RPC 2.0 over HTTP, authenticated with a VoiceOps API key sent in the `Authorization` header. It is entirely undocumented: it appears nowhere on voiceops.com, in the sitemap, or in any MCP registry, and there is no published way to obtain the key it requires. Because `tools/list` is auth-gated, no tool list is recorded in this profile.

VoiceOps publishes no developer portal, no API reference, and no OpenAPI, AsyncAPI, or GraphQL specification. A Freshdesk knowledge base (voiceopsassist.freshdesk.com) previously documented a Call Integration API and a Reporting API; it now returns 404. `api.voiceops.com` is a live host backing the app.voiceops.com application, but every anonymous path returns a Hapi/Boom `404` envelope and it exposes no discovery surface.

## Agent surfaces

- [MCP server](https://mcp.voiceops.com/mcp): Remote MCP endpoint. API-key auth; `tools/list` returns `-32000 Missing Authorization header` without one. Health check at `https://mcp.voiceops.com/health`.
- No A2A agent card is published (`/.well-known/agent-card.json` and `/.well-known/agent.json` 404 on every VoiceOps host).
- No `llms.txt` is served by VoiceOps; this file is generated by API Evangelist.

## Identity and discovery

- [OpenID Connect discovery](https://clerk.voiceops.com/.well-known/openid-configuration): Application sign-in issuer `https://clerk.voiceops.com` (RS256, PKCE S256, authorization_code + refresh_token)
- [OAuth 2.0 authorization server metadata](https://clerk.voiceops.com/.well-known/oauth-authorization-server): RFC 8414
- [security.txt](https://app.voiceops.com/.well-known/security.txt): RFC 9116; contact `engineering@voiceops.com`
- [Application](https://app.voiceops.com/): Customer sign-in
